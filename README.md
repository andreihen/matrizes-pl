# Laboratório de Matrizes 2.4

Aplicação web local para estudar Álgebra Linear com números racionais exatos.

## Executar

Abra `index.html` em um navegador moderno. Não existe backend nem dependência externa.

## Fluxo principal

1. Escolha o tipo de estudo logo na entrada.
2. Informe as dimensões e preencha/gera os dados.
3. Clique em **Usar esta matriz/sistema** ou **Usar estas matrizes**.
4. Escolha **ESTUDAR** para praticar ou **RESOLVER** para comparar uma solução completa.

## Recursos

- determinantes por Gauss, Laplace e Sarrus;
- inversa por `[A | I]`;
- sistemas lineares por matriz aumentada e escalonamento;
- gerador de sistemas a partir de uma solução conhecida, inclusive fracionária;
- operações com quantidade dinâmica de matrizes;
- expressões algébricas como `2A + 4B*C`;
- prática das matrizes intermediárias com correção célula por célula;
- frações exatas;
- importação/cópia JSON;
- histórico estruturado para os fluxos matriciais;
- interface responsiva para celular.
